# RailBerth

Choose one of three sample trains, pick a date, select seats, and reserve them under a passenger name. Each train and date has separate inventory. Bookings persist in your browser and tabs coordinate through Web Locks where supported.

```sh
python3 -m http.server 8033 --bind 127.0.0.1
```

Open http://localhost:8033 in a modern browser. Use sample names. Reservations are local to the browser profile and origin.
